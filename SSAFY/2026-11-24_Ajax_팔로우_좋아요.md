# 2026-11-24 TIL — Ajax로 팔로우 · 좋아요 비동기 구현 (Django + axios)

> 기존에 form 제출 + 새로고침으로 동작하던 팔로우·좋아요를
> **axios 요청 + JSON 응답 + DOM 조작**으로 바꿔서 새로고침 없이 동작하게 만들었다.

## 오늘 배운 것
- Ajax 요청이 처리되는 흐름
- Django 템플릿에 스크립트 넣을 자리 만들기 (`{% block script %}`)
- `data-*` 속성으로 HTML → JS에 값 넘기기
- axios POST 요청에 CSRF 토큰 보내기
- view 함수에서 `JsonResponse`로 응답하기
- 버튼이 여러 개일 때: `querySelectorAll` + `forEach`

## 1. Ajax 요청 흐름

```
① 사용자가 버튼 클릭 (submit 이벤트)
② 이벤트 리스너 콜백 실행 → preventDefault()로 새로고침 막기
③ axios가 서버로 요청 (내부적으로 XHR 객체 사용)
④ Django view가 처리 후 JSON으로 응답
⑤ .then() / async-await에서 응답 데이터 받기
⑥ 받은 데이터로 DOM 조작 (버튼 글자, 숫자 변경)
```

| | 기존 방식 | Ajax 방식 |
|---|---|---|
| 요청 | `<form action method>` 제출 | axios로 직접 요청 |
| 응답 | `redirect` → HTML 페이지 전체 | `JsonResponse` → 필요한 데이터만 |
| 화면 | 전체 새로고침 | 바뀐 부분만 JS로 수정 |

- **AJAX**: 새로고침 없이 서버와 데이터를 주고받는 기술 이름
- **axios**: AJAX 요청을 쉽게 보내도록 도와주는 라이브러리

## 2. 템플릿 준비

### base.html에 script 블록 만들기
`</body>` 바로 위에 자식 템플릿이 스크립트를 넣을 자리를 만든다.
(HTML 요소가 다 그려진 뒤에 스크립트가 실행되어야 `querySelector`로 찾을 수 있다.)

```html
<!-- base.html -->
<body>
  {% block content %}{% endblock content %}

  {% block script %}{% endblock script %}
</body>
```

### form에서 action, method 지우기
요청은 axios가 보낼 거라서 form은 **이벤트를 받는 용도**로만 남긴다.

```html
<form id="follow-form" data-user-id="{{ person.pk }}">
  {% csrf_token %}
  ...
</form>
```

## 3. data-* 속성: HTML → JavaScript로 값 넘기기

Django 템플릿 변수(`{{ person.pk }}`)는 서버에서 HTML을 만들 때 채워진다.
JS에서 이 값을 쓰려면 HTML 요소에 **사용자 지정 속성**으로 붙여 두고 꺼내 쓴다.

```html
<button id="btn" data-post-id="7" data-user-name="yeonju">버튼</button>

<script>
  const btn = document.querySelector('#btn')
  console.log(btn.dataset.postId)    // "7"
  console.log(btn.dataset.userName)  // "yeonju"
</script>
```

| HTML | JavaScript |
|---|---|
| `data-post-id` | `dataset.postId` |
| 케밥 케이스 (하이픈) | **카멜 케이스**로 자동 변환 |

- `data-` 뒤 이름에는 **대문자를 쓰지 않는다** (HTML에서 소문자로 바뀜).
- 꺼낸 값은 항상 **문자열**이다.

## 4. CSRF 토큰 보내기

Django는 POST 요청에 CSRF 토큰이 없으면 **403 Forbidden**으로 막는다.
form 제출 때는 `{% csrf_token %}`이 자동으로 같이 갔지만, axios로 보낼 때는 **직접 헤더에 넣어야** 한다.

```javascript
// {% csrf_token %}이 만든 숨겨진 input에서 값 꺼내기
const csrftoken = document.querySelector('[name=csrfmiddlewaretoken]').value

axios({
  method: 'post',
  url: `/accounts/${userId}/follow/`,
  headers: { 'X-CSRFToken': csrftoken },   // ⭐ 헤더 이름 정확히
})
```

- 그래서 form 안의 `{% csrf_token %}`은 지우면 안 된다. 토큰 값을 꺼내 쓰는 곳이기 때문.

## 5. 팔로우 비동기 구현

### views.py — redirect 대신 JsonResponse

```python
from django.http import JsonResponse
from django.shortcuts import get_object_or_404
from django.contrib.auth import get_user_model
from django.views.decorators.http import require_POST

@require_POST
def follow(request, user_pk):
    if not request.user.is_authenticated:
        return JsonResponse({'error': '로그인이 필요합니다.'}, status=401)

    me = request.user
    you = get_object_or_404(get_user_model(), pk=user_pk)

    if me == you:                                     # 나 자신은 팔로우 불가
        return JsonResponse({'error': '자기 자신은 팔로우할 수 없습니다.'}, status=400)

    if you.followers.filter(pk=me.pk).exists():
        you.followers.remove(me)
        is_followed = False
    else:
        you.followers.add(me)
        is_followed = True

    return JsonResponse({
        'is_followed': is_followed,
        'followers_count': you.followers.count(),
        'followings_count': you.followings.count(),
    })
```

- 숫자 계산은 **서버(view)에서** 하고 결과만 보낸다. JS에서 +1, -1 하면 실제 DB 값과 어긋날 수 있다.
- `me`, `you`로 이름을 붙이니 누가 누구를 팔로우하는지 읽기 쉬웠다.

### profile.html

```html
{% block content %}
  <h1>{{ person.username }}님의 프로필</h1>
  <div>
    팔로워: <span id="followers-count">{{ person.followers.count }}</span> /
    팔로잉: <span id="followings-count">{{ person.followings.count }}</span>
  </div>

  {% if request.user != person %}
    <form id="follow-form" data-user-id="{{ person.pk }}">
      {% csrf_token %}
      {% if request.user in person.followers.all %}
        <button type="submit">언팔로우</button>
      {% else %}
        <button type="submit">팔로우</button>
      {% endif %}
    </form>
  {% endif %}
{% endblock content %}

{% block script %}
<script src="https://cdn.jsdelivr.net/npm/axios/dist/axios.min.js"></script>
<script>
  const form = document.querySelector('#follow-form')

  // 내 프로필이면 form이 없으므로 확인 후 등록
  if (form) {
    form.addEventListener('submit', async function (event) {
      event.preventDefault()

      const userId = event.currentTarget.dataset.userId
      const csrftoken = document.querySelector('[name=csrfmiddlewaretoken]').value

      try {
        const response = await axios({
          method: 'post',
          url: `/accounts/${userId}/follow/`,
          headers: { 'X-CSRFToken': csrftoken },
        })
        const { is_followed, followers_count, followings_count } = response.data

        form.querySelector('button').textContent = is_followed ? '언팔로우' : '팔로우'
        document.querySelector('#followers-count').textContent = followers_count
        document.querySelector('#followings-count').textContent = followings_count
      } catch (error) {
        console.log(error.response)
      }
    })
  }
</script>
{% endblock script %}
```

- 수업에서는 `.then()` 방식으로 했고, 복습하면서 **async/await 방식**으로 다시 써 봤다. 동작은 같다.
- `const { a, b } = response.data`: 구조 분해 할당으로 응답 값을 한 번에 꺼낼 수 있다.

## 6. 좋아요 비동기 구현 — 버튼이 여러 개일 때

목록 페이지에는 게시글마다 좋아요 버튼이 있다.
→ `id`는 하나만 잡히니까 **`class`로 전부 선택**하고 `forEach`로 각각 리스너를 단다.
→ 각 버튼·숫자 태그는 **id에 게시글 pk를 붙여** 구분한다.

### views.py

```python
@require_POST
def likes(request, article_pk):
    if not request.user.is_authenticated:
        return JsonResponse({'error': '로그인이 필요합니다.'}, status=401)

    article = get_object_or_404(Article, pk=article_pk)
    if article.like_users.filter(pk=request.user.pk).exists():
        article.like_users.remove(request.user)
        is_liked = False
    else:
        article.like_users.add(request.user)
        is_liked = True

    return JsonResponse({
        'is_liked': is_liked,
        'like_count': article.like_users.count(),
    })
```

### index.html

```html
{% for article in articles %}
  <p>{{ article.title }}</p>
  <p>좋아요 <span id="like-count-{{ article.pk }}">{{ article.like_users.count }}</span>개</p>

  <form class="like-form" data-article-id="{{ article.pk }}">
    {% csrf_token %}
    <button type="submit" id="like-btn-{{ article.pk }}">
      {% if request.user in article.like_users.all %}좋아요 취소{% else %}좋아요{% endif %}
    </button>
  </form>
  <hr>
{% endfor %}
```

```javascript
const forms = document.querySelectorAll('.like-form')

forms.forEach((form) => {
  form.addEventListener('submit', function (event) {
    event.preventDefault()
    const articleId = event.currentTarget.dataset.articleId
    const csrftoken = form.querySelector('[name=csrfmiddlewaretoken]').value

    axios({
      method: 'post',
      url: `/articles/${articleId}/likes/`,
      headers: { 'X-CSRFToken': csrftoken },
    })
      .then((response) => {
        const { is_liked, like_count } = response.data
        document.querySelector(`#like-btn-${articleId}`).textContent = is_liked ? '좋아요 취소' : '좋아요'
        document.querySelector(`#like-count-${articleId}`).textContent = like_count
      })
      .catch((error) => console.log(error.response))
  })
})
```

### forEach 방식 vs 이벤트 위임 방식

| | `querySelectorAll` + `forEach` | 이벤트 위임 (버블링) |
|---|---|---|
| 리스너 개수 | 버튼 수만큼 | 부모에 1개 |
| 장점 | 버튼마다 독립적이라 읽기·디버깅 쉬움 | 나중에 추가된 버튼에도 자동 적용 |
| 어울리는 곳 | 페이지 로드 때 버튼이 다 그려져 있는 경우 | 무한 스크롤처럼 요소가 동적으로 늘어나는 경우 |

## 헷갈렸던 점 / 디버깅 체크리스트
- [ ] `preventDefault()` 빠뜨리면 axios 요청 전에 페이지가 새로고침돼 버린다.
- [ ] CSRF 헤더 이름은 `'X-CSRFToken'`. 없으면 **403**.
- [ ] **HTML id와 JS 선택자 이름이 정확히 같은지** 확인하기.
  - 예: HTML은 `liked-count-1`인데 JS에서 `#like-count-1`로 찾으면 `null` → `Cannot set properties of null` 에러
- [ ] 숫자 표시 `<span>`에 **처음 값**(`{{ article.like_users.count }}`)도 넣어 두기. 비워 두면 클릭 전까지 숫자가 안 보인다.
- [ ] 같은 `id`를 페이지에 두 번 쓰지 않기. `querySelector`는 첫 번째만 잡는다.
- [ ] URL은 `http://127.0.0.1:8000/...`처럼 주소를 고정하지 말고 `/articles/...` 상대 경로로. 배포하면 주소가 바뀐다.
- [ ] 로그인 안 한 사용자에게 `redirect`를 주면 axios는 로그인 페이지 HTML을 받아 버린다. Ajax용 view는 `401` JSON으로 응답하는 게 처리하기 편하다.
- [ ] 에러가 나면 개발자 도구 **Network 탭**에서 요청 URL, 상태 코드, 응답 내용을 먼저 확인하기.
