## 1. 이벤트와 addEventListener

**이벤트**: 브라우저에서 일어나는 사건 (클릭, 입력, 제출, 복사 등)

```javascript
대상.addEventListener('이벤트 종류', 실행할 함수)
```

```html
<button id="like-btn">좋아요</button>
<p id="like-count">0</p>

<script>
  let likes = 0
  const likeBtn = document.querySelector('#like-btn')

  likeBtn.addEventListener('click', function () {
    likes += 1
    document.querySelector('#like-count').textContent = likes
  })
</script>
```

- "이 버튼을 **지켜보다가** 클릭되면 이 함수를 실행해 줘"라고 등록해 두는 것.
- 두 번째 인자로 넘기는 함수는 지금 바로 실행되는 게 아니라, 이벤트가 일어났을 때 **나중에 불리는 함수(콜백 함수)** 이다.

## 2. innerHTML vs textContent vs innerText

| | 하는 일 | 장점 | 주의할 점 |
|---|---|---|---|
| `innerHTML` | 문자열을 **HTML로 해석**해서 넣음 | 태그(`<strong>` 등)까지 넣을 수 있음 | 사용자 입력을 넣으면 **XSS 공격**에 취약, DOM을 다시 만들어서 느림 |
| `textContent` | **글자 그대로** 넣음 / 숨겨진 요소 글자까지 전부 가져옴 | 안전하고 빠름 | 화면에 보이는지는 신경 안 씀 |
| `innerText` | **화면에 보이는 글자만** 가져옴 | `display: none`인 글자는 빼고 가져옴 | CSS를 계산해야 해서 `textContent`보다 느림 |

```html
<div id="msg">
  <span style="display: none;">비밀</span>
  안녕
</div>

<script>
  const msg = document.querySelector('#msg')
  console.log(msg.textContent)  // 비밀 안녕  (숨긴 것까지)
  console.log(msg.innerText)    // 안녕       (보이는 것만)

  msg.innerHTML = '<strong>굵게</strong>'    // 굵은 글씨로 보임
  msg.textContent = '<strong>굵게</strong>'  // 태그가 글자 그대로 보임
</script>
```

> **결론**: 글자만 바꿀 때는 `textContent`를 기본으로 쓰자. HTML 구조까지 바꿔야 할 때만 `innerHTML`, 그때도 사용자 입력은 넣지 않기.

## 3. input 이벤트와 classList.toggle

- `input` 이벤트: 입력창 값이 **바뀔 때마다** 실행 → 실시간 미리보기에 사용
- 콜백 함수의 첫 번째 매개변수 `event`에 이벤트 정보가 들어 있다.
  - `event.target`: 이벤트가 일어난 요소
  - `event.target.value`: 입력창에 쓴 값

```html
<style>
  .highlight { color: tomato; }
</style>

<input type="text" id="nickname">
<h2 id="preview"></h2>
<button id="color-btn">색 바꾸기</button>

<script>
  const preview = document.querySelector('#preview')

  document.querySelector('#nickname').addEventListener('input', function (event) {
    preview.textContent = event.target.value
  })

  document.querySelector('#color-btn').addEventListener('click', function () {
    preview.classList.toggle('highlight')
  })
</script>
```

- `classList.toggle('클래스')`: 클래스가 **없으면 추가하고 `true`**, **있으면 제거하고 `false`** 를 반환한다. 스위치처럼 껐다 켰다 할 때 사용.

## 4. 이벤트 취소: event.preventDefault() ⭐ 시험 자주 나옴

브라우저가 원래 하던 **기본 동작을 막는** 메서드.

| 이벤트 | 기본 동작 | 막으면 |
|---|---|---|
| `submit` | 폼 데이터를 보내고 페이지 이동(새로고침) | 페이지 이동 없이 JS로 직접 처리 가능 |
| `copy` | 선택한 글자 복사 | 복사 안 됨 |
| `a` 태그 `click` | 링크로 이동 | 이동 안 됨 |

```html
<form id="signup">
  <input type="text" id="email">
  <button>가입</button>
</form>

<script>
  document.querySelector('#signup').addEventListener('submit', function (event) {
    event.preventDefault()   // 새로고침 막기

    const email = document.querySelector('#email').value
    if (!email.trim()) {     // 공백만 있으면 빈 문자열 → false
      alert('이메일을 입력하세요')
      return
    }
    console.log('제출:', email)
  })
</script>
```

> 나중에 **비동기 통신(axios 등)** 으로 폼 데이터를 보낼 때 새로고침을 막기 위해 자주 쓴다.

## 5. 실습 정리

### (1) 랜덤 번호 뽑기 — lodash
- **lodash**: JavaScript 기본 기능에 없는 편리한 함수들을 모아 둔 라이브러리 (`_`로 사용)
- CDN `<script>`로 불러와서 사용

```javascript
_.range(1, 46)              // [1, 2, ..., 45]  (파이썬 range처럼 끝은 포함 안 함)
_.sampleSize(배열, 6)        // 배열에서 중복 없이 6개 랜덤 추출
_.cloneDeep(객체)            // 깊은 복사 (안쪽 객체까지 새로 복사)
_.merge(객체1, 객체2)         // 객체 병합 (안쪽 객체까지 합쳐 줌)
```

**DOM 조작 흐름**
1. `document.createElement('div')`로 요소 만들기
2. `classList.add('클래스')`로 CSS 적용
3. `textContent`로 내용 채우기, `style.backgroundColor`로 스타일 지정
4. `부모.appendChild(자식)`로 맨 뒤에 붙이기
5. `부모.insertBefore(새요소, 부모.firstChild)`로 **맨 앞에** 붙이기 (최신 결과가 위로)

### (2) Todo 리스트
- 콜백 함수를 **따로 정의해 두고** 이름으로 넘기는 방식 (실무에서 많이 씀)

```javascript
const addTodo = function (event) {
  event.preventDefault()
  const input = document.querySelector('.todo-input')
  const text = input.value

  if (text.trim()) {
    const li = document.createElement('li')
    li.textContent = text
    document.querySelector('ul').appendChild(li)
  } else {
    alert('할 일을 입력하세요')
  }
  event.target.reset()   // event.target = form → 입력값 초기화
}

document.querySelector('form').addEventListener('submit', addTodo)
// addTodo()가 아니라 addTodo! 괄호를 붙이면 바로 실행돼 버린다
```

## 6. 이벤트 버블링

**버블링**: 자식 요소에서 일어난 이벤트가 **부모 → 조상 → document까지 위로 전파**되는 것. (물방울이 위로 올라가는 모습)

```html
<div id="box">
  <button id="inner-btn">클릭</button>
</div>

<script>
  document.querySelector('#box').addEventListener('click', function () {
    console.log('div')
  })
  document.querySelector('#inner-btn').addEventListener('click', function (event) {
    console.log('button')
    // event.stopPropagation()  // 이 줄을 켜면 버블링이 멈춰서 'div'는 안 찍힘
  })
</script>
```
버튼 클릭 시 출력: `button` → `div`

### 이벤트 위임 (버블링 활용)
자식마다 리스너를 달지 않고 **부모에 한 번만** 등록해서 처리하는 방법.

```html
<ul id="menu">
  <li>김밥</li>
  <li>라면</li>
  <li>떡볶이</li>
</ul>

<script>
  document.querySelector('#menu').addEventListener('click', function (event) {
    if (event.target.tagName === 'LI') {   // tagName은 항상 대문자!
      console.log('주문:', event.target.textContent)
    }
  })
</script>
```

- 장점: 리스너 1개로 충분하고, **나중에 추가되는 li에도 자동으로 적용**된다.
- `tagName`은 대문자로 반환되므로 `'li'`가 아니라 `'LI'`로 비교해야 한다.
- 대부분의 이벤트는 버블링되지만 `focus`처럼 버블링되지 않는 이벤트도 있다.

## 7. event.target vs event.currentTarget

| | 의미 | 위 메뉴 예시에서 |
|---|---|---|
| `event.target` | 이벤트가 **실제로 일어난** 요소 | 클릭한 `li` |
| `event.currentTarget` | 리스너가 **등록된** 요소 | `ul#menu` |

- `input` 이벤트처럼 리스너를 단 요소에서 직접 이벤트가 일어나면 둘이 **같은 요소**를 가리킨다.
- 이벤트 위임처럼 버블링이 끼면 둘이 **달라진다**.

## 8. 리스너 안의 this와 화살표 함수

```javascript
btn.addEventListener('click', function () {
  console.log(this)   // btn (리스너가 등록된 요소 = event.currentTarget)
})

btn.addEventListener('click', () => {
  console.log(this)   // window (화살표 함수는 자기 this가 없어서 바깥 this를 씀)
})
```

### 화살표 함수를 피해야 할 때
1. **이벤트 리스너 콜백**에서 `this`를 쓸 때 → `function` 사용
2. **객체의 메서드**에서 `this`로 그 객체를 쓸 때 → `function`(또는 메서드 축약형) 사용
3. **생성자 함수** → 화살표 함수로는 `new`로 객체를 만들 수 없음
4. 함수 표현식(`const f = () => {}`)은 호이스팅되지 않으므로 **정의한 뒤에 호출**해야 함

### 화살표 함수가 잘 맞을 때
1. `this`가 필요 없는 짧은 함수
2. `forEach`, `map` 등의 콜백 → 바깥(예: 메서드 안)의 `this`를 그대로 쓸 수 있음

---

## 헷갈렸던 점 / 기억할 것
- `this`(function 콜백)는 **`event.currentTarget`** 과 같다. 클릭한 자식(`event.target`)이 아닐 수 있다.
- `addEventListener('submit', addTodo)`에 괄호를 붙이지 않기.
- 사용자 입력을 화면에 넣을 때는 `innerHTML` 말고 `textContent`.
