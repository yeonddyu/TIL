## 1. C 프로그램의 기본 구조

```c
#include <stdio.h>      // 표준 입출력 라이브러리를 불러온다 (printf가 여기 들어 있음)

int main() {            // 프로그램이 시작되는 곳. 모든 C 프로그램에는 main이 꼭 하나 있다
    printf("Hi, C!");   // 문장 끝에는 세미콜론(;)
    return 0;           // 프로그램이 정상 종료됐다는 뜻으로 운영체제에 0을 돌려준다
}
```

- `#include <stdio.h>`: "출력 기능이 들어 있는 도구 상자를 가져와줘"라는 뜻. 없으면 `printf`를 쓸 수 없다.
- `int main()`: 프로그램의 입구. `int`는 main이 끝날 때 정수(int)를 돌려준다는 의미.
- `return 0;`: "문제 없이 끝났어"라고 알리는 신호.
  - C99 이후로는 `main`에서 `return 0;`을 생략해도 자동으로 0을 반환한다. 그래도 습관적으로 써 주는 게 좋다.

## 2. printf로 출력하기

- 큰따옴표(`" "`) 안의 내용이 **그대로** 화면에 출력된다.
- 숫자, 기호, 공백도 문자열 안에 있으면 글자로 취급되어 그대로 나온다.

```c
#include <stdio.h>

int main() {
    printf("2026 SSAFY!");   // 출력: 2026 SSAFY!
    printf("***");           // 출력: ***  (앞 줄 바로 뒤에 붙는다)
    return 0;
}
```
출력 결과
```
2026 SSAFY!***
```

> **포인트**: `printf`는 자동으로 줄을 바꿔주지 않는다. 여러 번 호출해도 줄바꿈이 없으면 한 줄에 이어서 출력된다.

## 3. 줄바꿈 `\n`과 이스케이프 시퀀스

`\`(역슬래시) 뒤에 특정 문자를 붙이면 특별한 의미를 가진다.

| 이스케이프 시퀀스 | 의미 |
|---|---|
| `\n` | 줄바꿈 |
| `\t` | 탭 |
| `\\` | 역슬래시 `\` 출력 |
| `\"` | 큰따옴표 `"` 출력 |
| `%%` | `%` 출력 (printf 전용) |

```c
#include <stdio.h>

int main() {
    printf("Python\n");
    printf("C\tJava\n");
    printf("\"Hello\" \\ 100%%\n");
    return 0;
}
```
출력 결과
```
Python
C	Java
"Hello" \ 100%
```

> **Python과 비교**: Python의 `print()`는 끝에 자동으로 줄바꿈을 넣지만, C의 `printf()`는 `\n`을 직접 써야 한다.

## 헷갈렸던 점 / 기억할 것
- 세미콜론(`;`)을 빼먹으면 컴파일 에러가 난다.
- C 파일 확장자는 `.c` (`.cpp`는 C++).
- `int main ()`처럼 괄호 앞에 공백이 있어도 동작은 같다. 다만 스타일은 하나로 통일하자.
