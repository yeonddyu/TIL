## 이 단계에서 정리한 개념

### 1. if / elif / else

```python
if 조건1:
    ...        # 조건1이 참일 때
elif 조건2:
    ...        # 조건1은 거짓, 조건2가 참일 때
else:
    ...        # 위 조건이 모두 거짓일 때
```

- 위에서부터 차례로 검사하고, **처음 참인 블록 하나만** 실행한다.
- 범위를 나눌 때는 **큰 값부터** 검사하면 `elif`에 위쪽 범위를 다시 적지 않아도 된다.

```python
# 큰 값부터 → 간단
if score >= 90: ...
elif score >= 80: ...    # 이미 90 미만인 것만 여기 도착

# 같은 뜻을 풀어서 쓰면
if score >= 90: ...
elif 80 <= score < 90: ...   # 파이썬은 연쇄 비교도 가능
```

### 2. 비교 · 논리 연산자

| 연산자 | 의미 |
|---|---|
| `==` / `!=` | 같다 / 다르다 |
| `>` `<` `>=` `<=` | 대소 비교 |
| `and` | 둘 다 참 |
| `or` | 하나라도 참 |
| `not` | 참/거짓 뒤집기 |

- 우선순위: `not` > `and` > `or`. 헷갈리면 **괄호**로 묶어서 의도를 분명하게 한다.

### 3. 배수 판별은 `%`

```python
n % 4 == 0      # 4의 배수
n % 100 != 0    # 100의 배수가 아님
```

- 윤년 조건: `(year % 4 == 0 and year % 100 != 0) or year % 400 == 0`

### 4. 중첩 if

```python
if x > 0:
    if y > 0:
        ...
```

- 조건이 두 단계(먼저 x, 그다음 y)로 나뉠 때 읽기 쉽다.
- `and`로 풀어서 쓸 수도 있다: `if x > 0 and y > 0:`

### 5. 입력 형식 확인

- 한 줄에 여러 값: `A, B = map(int, input().split())`
- 한 줄에 하나씩: `x = int(input())`, `y = int(input())`
- 형식이 다르면 `ValueError`가 나므로 문제의 입력 형식을 먼저 확인하자.
