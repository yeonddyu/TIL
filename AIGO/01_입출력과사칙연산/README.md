## 이 단계에서 정리한 개념

### 1. 입력 받기

```python
a = int(input())                    # 정수 하나
a, b = map(int, input().split())    # 한 줄에 공백으로 구분된 정수 여러 개
a, b, c = map(int, input().split())
s = input()                         # 문자열 그대로
```

- `input()`은 항상 **문자열**을 돌려준다 → 계산하려면 `int()`로 바꿔야 한다.
- `split()`: 공백 기준으로 잘라서 리스트로
- `map(int, ...)`: 리스트의 모든 요소에 `int`를 적용

### 2. 사칙연산

| 연산자 | 의미 | 예 (`7`, `3`) |
|---|---|---|
| `+` `-` `*` | 더하기, 빼기, 곱하기 | `10`, `4`, `21` |
| `/` | 나누기 (결과는 **실수**) | `2.3333333333333335` |
| `//` | 몫 (정수 나눗셈) | `2` |
| `%` | 나머지 | `1` |

- `/`는 정수끼리 나눠도 실수가 나온다. 몫만 필요하면 `//`.
- 실수 출력은 오차 허용 범위를 확인하자. 보통 그대로 `print()` 해도 된다.
- 모듈러 성질: `(A + B) % C == ((A % C) + (B % C)) % C`, 곱셈도 같은 성질이 성립한다.

### 3. 자릿수 꺼내기

```python
n = 385
print(n % 10)           # 5  (일의 자리)
print(n // 10 % 10)     # 8  (십의 자리)
print(n // 100)         # 3  (백의 자리)

# 문자열로 바꿔서 꺼내는 방법도 있다
s = str(n)
print(s[2], s[1], s[0]) # 5 8 3
```

### 4. 출력

```python
print('Hello')                  # 기본: 끝에 줄바꿈
print(a, b)                     # 공백으로 구분해서 출력
print(a, b, sep='')             # 구분자 없이
print(f'{a} + {b} = {a + b}')   # f-string
print(s + '??!')                # 문자열 이어 붙이기
```

### 5. 특수문자 그대로 출력하기 (그림 출력 문제)

- 역슬래시 `\`는 이스케이프 문자의 시작이라 그대로 쓰면 의도와 다르게 출력된다.
  - `\\` → `\` 하나 출력, `\'` → `'` 출력
- 방법 1: 이스케이프 처리
  ```python
  print('\\(o_o)/')
  ```
- 방법 2: **raw 문자열** `r''` — 역슬래시를 글자 그대로 취급 (단, 문자열이 `\`로 끝나면 안 됨)
  ```python
  print(r'\(o_o)/')
  ```
- 방법 3: 큰따옴표·작은따옴표를 섞어서 따옴표 충돌 피하기
  ```python
  print("it's ok")
  ```

## 헷갈렸던 점
- `input().split()` 결과는 문자열 리스트라서 `map(int, ...)`를 빠뜨리면 `'1' + '2' = '12'`가 된다.
- `/`와 `//`를 문제 조건에 맞게 구분하기.
