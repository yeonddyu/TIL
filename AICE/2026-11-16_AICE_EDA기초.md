## 2. 데이터 구조 확인 4종 세트

```python
df = pd.read_csv('data.csv')

print(df.shape)              # (행 수, 열 수)
print(df.head())             # 앞 5행 (괄호 안에 숫자를 넣으면 개수 변경)
print(df.isnull().sum())     # 컬럼별 결측치 개수
print(df['target'].describe())  # 개수, 평균, 표준편차, 최솟값, 사분위수, 최댓값
```

- 데이터를 처음 받으면 **"얼마나 큰지 → 어떻게 생겼는지 → 빈칸은 없는지 → 예측할 값은 어떤 범위인지"** 순서로 확인한다.
- `isnull().sum()`에서 0이 아닌 컬럼은 나중에 결측치 처리 대상이다.
- `describe()`에서 평균과 중앙값(50%)이 비슷하면 분포가 크게 치우치지 않았다고 볼 수 있다.

## 3. 범주별 분포 비교: boxplot vs barplot

```python
# 박스플롯: 범주별 '분포 전체'를 본다
sns.boxplot(data=df, x='category', y='target')
plt.title('범주별 타깃 분포')
plt.show()

# 막대그래프: 범주별 '평균'을 본다
sns.barplot(data=df, x='category', y='target')
plt.title('범주별 타깃 평균')
plt.show()
```

| | boxplot | barplot |
|---|---|---|
| 보여주는 것 | 중앙값, 사분위수(Q1~Q3), 이상치 | 평균 (+ 신뢰구간 막대) |
| 언제 쓰나 | 퍼짐 정도와 이상치까지 보고 싶을 때 | 그룹 간 평균 차이를 간단히 비교할 때 |

- `sns.barplot`은 개수를 세는 그래프가 아니라 **y의 평균**을 그린다. 막대 위 검은 선은 신뢰구간이다.
- `data=df`로 넘기고 `x`, `y`에 컬럼 이름을 쓰는 방식이 더 깔끔하다.

## 4. groupby + agg로 그룹별 통계 구하기

```python
stat = df.groupby('category')['target'].agg(['mean', 'median'])
stat = stat.sort_values('median', ascending=False)   # 중앙값 기준 내림차순
print(stat.round(3))
```

- `groupby('A')['B']`: "A 값이 같은 행끼리 묶어서 B를 보겠다"
- `.agg([...])`: 여러 통계를 **한 번에** 계산해서 컬럼으로 붙여준다. `.mean()`, `.median()`을 따로 하면 한 가지만 나온다.
- `sort_values('컬럼', ascending=False)`: 큰 값부터 정렬

### 평균과 중앙값을 같이 보는 이유
- 평균은 이상치에 끌려가지만, 중앙값은 잘 흔들리지 않는다.
- 둘이 비슷하면 그룹 안 분포가 고른 것이고, 차이가 크면 한쪽으로 치우쳤거나 이상치가 있다는 신호다.

## 헷갈렸던 점 / 기억할 것
- 문제에서 **평균과 중앙값**을 요구하면 `agg(['mean', 'median'])`으로 둘 다 출력하기. 하나만 쓰면 부분 점수도 어렵다.
- 출력 조건(예: 앞 5행 출력)을 하나씩 체크하면서 빠진 게 없는지 확인하기.
