## 1. Pandas란?

- 엑셀 표처럼 **행과 열**이 있는 데이터를 다루는 라이브러리
- 내부적으로 NumPy 배열을 사용한다.

| 자료구조 | 모양 | 예 |
|---|---|---|
| **Series** | 1차원 (열 하나) | `df['가격']` |
| **DataFrame** | 2차원 (표 전체) | `df` |

```python
import pandas as pd

menu = pd.DataFrame({
    '메뉴': ['아메리카노', '라떼', '바닐라라떼', '녹차'],
    '가격': [4000, 4500, 5000, 4800],
    '분류': ['커피', '커피', '커피', '티'],
    '판매중': [True, True, False, True],
})
```

- 딕셔너리의 **키 → 열 이름**, **값 리스트 → 열 데이터**
- 왼쪽에 자동으로 붙는 `0, 1, 2, 3`이 **인덱스**(행 이름)

## 2. CSV 저장 · 불러오기

```python
menu.to_csv('menu.csv', index=False, encoding='utf-8-sig')
df = pd.read_csv('menu.csv', encoding='utf-8-sig')
```

| 옵션 | 의미 |
|---|---|
| `index=False` | 인덱스는 저장하지 않음 |
| `encoding='utf-8-sig'` | 한글을 엑셀에서 열어도 안 깨지게 저장 |
| `encoding='cp949'` | 윈도우 한글 인코딩 (오래된 한글 CSV 읽을 때) |

- `to_csv()`는 기본적으로 **인덱스까지 저장**한다.
  → 다시 읽으면 `Unnamed: 0`이라는 쓸모없는 열이 생긴다.
  → 저장할 때 `index=False`를 주거나, 읽을 때 `pd.read_csv('파일', index_col=0)`으로 해결.
- 한글이 깨지면 `encoding`을 바꿔 본다.

## 3. 열 선택

```python
df['가격']              # 열 하나 → Series
df[['메뉴', '가격']]     # 열 여러 개 → DataFrame (대괄호 두 겹!)
```

- 열 여러 개는 **리스트로 감싸서** 넘기기 때문에 대괄호가 두 겹이다.

## 4. 행 선택: loc vs iloc ⭐

| | `loc` | `iloc` |
|---|---|---|
| 기준 | **이름(라벨)** — 인덱스 값, 열 이름 | **위치(순서 번호)** — 0, 1, 2... |
| 슬라이싱 끝 | **포함** | **미포함** (파이썬 슬라이싱과 같음) |
| 열 지정 | `'가격'` 같은 열 이름 | `1` 같은 열 번호 |

```python
df.loc[0]                    # 인덱스가 0인 행 전체
df.loc[0:2]                  # 인덱스 0, 1, 2 → 3개 (끝 포함!)
df.loc[0:2, ['메뉴', '가격']]  # 0~2행의 메뉴, 가격 열

df.iloc[0]                   # 첫 번째 행
df.iloc[0:2]                 # 0, 1번째 행 → 2개 (끝 미포함)
df.iloc[:, 1:3]              # 모든 행, 1~2번째 열
```

- 쉼표 앞은 **행**, 쉼표 뒤는 **열**: `df.loc[행, 열]`, `df.iloc[행, 열]`
- 인덱스가 0, 1, 2…인 기본 상태에서는 `loc`과 `iloc`이 비슷해 보이지만, **슬라이싱 끝 포함 여부가 다르다.**

## 5. 조건 필터링

```python
df[df['가격'] >= 4800]                 # 가격 4800 이상
df[df['판매중'] == True]                # 판매 중인 메뉴 (df[df['판매중']]과 같음)
df[df['메뉴'].isin(['라떼', '녹차'])]    # 여러 값 중 하나와 일치

# 조건 여러 개: & (그리고), | (또는) + 각 조건을 괄호로
df[(df['분류'] == '커피') & (df['가격'] < 5000)]
df[(df['분류'] == '티') | (df['판매중'] == False)]

# 조건에 맞는 행의 특정 열만
df.loc[df['가격'] >= 4800, '메뉴']
```

### 동작 원리
1. `df['가격'] >= 4800` → 행마다 `True/False`가 담긴 Series
2. `df[그 Series]` → `True`인 행만 남김 (NumPy 불리언 인덱싱과 같다)

- `and`, `or`를 쓰면 에러가 난다. **반드시 `&`, `|`와 괄호.**
- `~`를 붙이면 반대: `df[~df['메뉴'].isin(['녹차'])]` → 녹차 제외

## 6. 데이터 결합: concat vs merge

### concat — 단순히 이어 붙이기

```python
jan = pd.DataFrame({'메뉴': ['라떼', '녹차'], '판매량': [30, 12]})
feb = pd.DataFrame({'메뉴': ['라떼', '모카'], '판매량': [25, 18]})

pd.concat([jan, feb])                      # 위아래로 (axis=0, 기본)
pd.concat([jan, feb], ignore_index=True)   # 인덱스를 0부터 다시 매김
pd.concat([jan, feb], axis=1)              # 좌우로
```

- 그냥 붙이면 인덱스가 `0, 1, 0, 1`처럼 **중복**된다 → `ignore_index=True`

### merge — 공통 열(키)을 기준으로 합치기 (SQL의 JOIN)

```python
orders = pd.DataFrame({'메뉴ID': [1, 2, 3, 5], '수량': [2, 1, 4, 3]})
items  = pd.DataFrame({'메뉴ID': [1, 2, 3, 4], '메뉴': ['아메리카노', '라떼', '녹차', '모카']})

pd.merge(orders, items, on='메뉴ID', how='inner')
```

| `how` | 남는 행 | 위 예시 결과 |
|---|---|---|
| `inner` (기본) | 양쪽에 **다 있는** 키 | 1, 2, 3 |
| `left` | **왼쪽** 키 전부 | 1, 2, 3, 5 (5의 메뉴는 NaN) |
| `right` | **오른쪽** 키 전부 | 1, 2, 3, 4 (4의 수량은 NaN) |
| `outer` | **양쪽** 키 전부 | 1, 2, 3, 4, 5 |

> SQLD에서 배운 INNER / LEFT OUTER / RIGHT OUTER / FULL OUTER JOIN과 같은 개념이다.

| | concat | merge |
|---|---|---|
| 기준 | 없음, 그냥 이어 붙임 | **공통 열(키)** 값을 맞춰서 붙임 |
| 용도 | 같은 형식의 데이터 합치기 (1월 + 2월) | 다른 테이블의 정보 연결 (주문 + 메뉴 정보) |

## 7. groupby — 그룹별 집계

```python
sales = pd.DataFrame({
    '분류': ['커피', '커피', '티', '티', '커피', '디저트'],
    '매장': ['강남', '역삼', '강남', '역삼', '강남', '역삼'],
    '매출': [120, 90, 40, 55, 100, 70],
})

sales.groupby('분류')['매출'].sum()          # 분류별 매출 합계
sales.groupby('분류')['매출'].agg(['mean', 'max', 'count'])   # 여러 통계 한 번에
sales.groupby(['분류', '매장'])['매출'].sum()  # 두 기준으로 묶기
```

### reset_index — 그룹 이름을 다시 열로

```python
result = sales.groupby('분류')['매출'].mean().reset_index()
result.columns = ['분류', '평균매출']        # 열 이름 바꾸기

# 같은 결과를 처음부터 DataFrame으로
sales.groupby('분류', as_index=False)['매출'].mean()
```

- `groupby` 결과는 그룹 이름(`커피`, `티`…)이 **인덱스**로 올라간다.
- `reset_index()`를 하면 인덱스가 다시 **일반 열**이 되어 다루기 쉬워진다.
- `groupby` 읽는 법: **"분류별로 묶어서, 매출 열의, 평균을 구해라"**

## 헷갈렸던 점 / 기억할 것
- `df.loc[0]`은 **0번 행 전체**를 가져온다. 열까지 지정하려면 `df.loc[0, '가격']`.
- `df.iloc[:, 1:3]`은 쉼표 **뒤**라서 행이 아니라 **열** 1~2번째.
- `loc` 슬라이싱은 끝 포함, `iloc`은 끝 미포함.
- 주피터 셀은 **마지막 줄의 결과만** 화면에 보여준다. 필터링 여러 개를 한 셀에 쓰면 마지막 것만 보이므로 셀을 나누거나 `print()`나 `display()`를 쓴다.
- 여러 조건은 `&`, `|` + 괄호. `and`, `or`는 에러.
- `to_csv`는 `index=False`를 습관처럼 붙이자.
