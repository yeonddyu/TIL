## 1. 데이터 구조 파악

```python
import pandas as pd

df = pd.read_csv('titanic.csv')

df.head(3)    # 위에서 3행 (기본 5행)
df.tail()     # 아래에서 5행
df.info()     # 열 이름, 결측치 아닌 개수, 자료형
```

### info()에서 확인할 것
| 항목 | 보는 이유 | 타이타닉 예 |
|---|---|---|
| 전체 행 수 | 데이터 크기 | 891행 |
| Non-Null Count | **결측치** 찾기 (전체 행 수보다 작으면 결측) | Age 714, Cabin 204, Embarked 889 |
| Dtype | 수치형 / 문자형 구분 → 인코딩 대상 찾기 | Sex, Embarked는 문자형 |

- Cabin은 891개 중 204개만 있어서 **77% 이상이 결측** → 열을 지울지 고민해야 한다.
- Age는 약 20% 결측 → 중앙값 등으로 채우는 방법을 고민한다.

## 2. 수치형 데이터: describe()

```python
df.describe()                     # 수치형 열만 요약
df.describe(include='object')     # 문자형 열 요약 (개수, 고유값 수, 최빈값, 최빈값 빈도)
```

| 항목 | 의미 |
|---|---|
| count | 결측치를 **제외한** 개수 |
| mean | 평균 |
| std | 표준편차 |
| min / max | 최솟값 / 최댓값 |
| 25% | 1사분위수 (Q1) |
| 50% | 중앙값 (Q2, median) |
| 75% | **3사분위수 (Q3)** |

### 통계량 직접 계산

```python
age = df['Age']

age.mean()           # 평균
age.median()         # 중앙값
age.std()            # 표준편차
age.var()            # 분산 (= 표준편차²)
age.min(), age.max()
age.quantile(0.25)   # Q1
age.quantile(0.75)   # Q3

IQR = age.quantile(0.75) - age.quantile(0.25)

age.rank(pct=True)[0]   # 0번 행의 값이 전체에서 하위 몇 %에 있는지 (0~1)
```

### 통계량 해석하는 법 ⭐

**① 평균 vs 중앙값**
- 평균은 이상치에 끌려가고, 중앙값은 잘 흔들리지 않는다.
- **평균 > 중앙값** → 큰 값 쪽으로 긴 꼬리 (오른쪽 꼬리, 양의 왜도)
- **평균 < 중앙값** → 작은 값 쪽으로 긴 꼬리

| 열 | 평균 | 중앙값 | 해석 |
|---|---|---|---|
| Age | 29.7 | 28.0 | 비슷함 → 분포가 크게 치우치지 않음 |
| Fare | 32.2 | 14.5 | 평균이 2배 이상 → **오른쪽으로 긴 꼬리, 큰 이상치 존재** (max 512) |

**② 표준편차**
- 크면 값들이 평균에서 멀리 퍼져 있고, 작으면 평균 근처에 모여 있다.
- Fare는 평균이 32인데 표준편차가 50 → 값의 차이가 매우 크다.

**③ 사분위수와 IQR**
- IQR = Q3 - Q1 → **가운데 50% 데이터**가 퍼진 폭
- 이상치 기준: `Q1 - 1.5 × IQR`보다 작거나 `Q3 + 1.5 × IQR`보다 크면 이상치

**④ 범위 확인**
- 이상한 값이 없는지 본다. 예: Age의 최솟값 0.42 → 1세 미만 아기라서 오류가 아니라 정상 값

> pandas의 `.std()`, `.var()`는 표본 기준(n-1로 나눔)이 기본이다. NumPy의 `np.std()`와 값이 조금 다를 수 있다.

## 3. 범주형 데이터

범주형 데이터를 살펴보는 이유
- **편향 확인**: 한 범주에 데이터가 몰려 있으면 모델이 그 범주만 잘 맞히게 된다.
- **전처리 전략**: 범주가 몇 개인지에 따라 원-핫 인코딩을 할지, 범주를 합칠지 정한다.

```python
df['Pclass'].value_counts()                  # 범주별 개수 (많은 순)
df['Pclass'].value_counts(normalize=True)    # 범주별 비율 (0~1)
(df['Pclass'].value_counts(normalize=True) * 100).round(1)   # 퍼센트로

df['Embarked'].unique()     # 어떤 값들이 있는지 (결측치 NaN도 나옴)
df['Embarked'].nunique()    # 종류 개수 (NaN은 기본적으로 제외)
```

- `value_counts()`는 기본적으로 **NaN을 세지 않는다**. 결측치도 보려면 `value_counts(dropna=False)`.
- 퍼센트로 바꿀 때는 **곱한 다음 반올림**해야 `55.1`처럼 깔끔하게 나온다. 반올림 후 곱하면 소수점 오차가 남을 수 있다.

## 4. 범주별 관계 분석: groupby

```python
# 객실 등급별 생존율
df.groupby('Pclass')['Survived'].mean()

# 성별 + 객실 등급별 생존율
df.groupby(['Sex', 'Pclass'])['Survived'].mean()

# 등급별 운임 통계 여러 개
df.groupby('Pclass')['Fare'].agg(['mean', 'median', 'std'])
```

- `Survived`처럼 **0과 1로 된 열의 평균 = 1의 비율** → 그대로 생존율이 된다.

### 결과에서 읽은 것
- 생존율: 1등석 63% > 2등석 47% > 3등석 24% → **객실 등급이 생존에 큰 영향**
- 성별까지 나누면 여성 1·2등석은 90% 이상, 남성 2·3등석은 15% 이하 → **성별과 등급을 같이 보면 차이가 더 뚜렷하다**
- 1등석 운임은 평균 84, 중앙값 60, 표준편차 78 → 같은 1등석 안에서도 운임 차이가 크다.

## 5. Matplotlib 기본 구조

```python
import matplotlib.pyplot as plt

plt.rcParams['font.family'] = 'Malgun Gothic'   # 윈도우 한글 폰트 (맥: AppleGothic)
plt.rcParams['axes.unicode_minus'] = False      # 음수 기호 깨짐 방지

fig, ax = plt.subplots(figsize=(8, 5))   # fig: 그림판 전체, ax: 그래프 한 칸
ax.plot([1, 2, 3, 4], [3, 7, 5, 9])      # 꺾은선
ax.set_title('제목')
ax.set_xlabel('X축')
ax.set_ylabel('Y축')
plt.tight_layout()                        # 겹치지 않게 간격 자동 조정
plt.show()
```

### 여러 그래프 나란히 그리기

```python
fig, axes = plt.subplots(1, 2, figsize=(12, 5))   # 1행 2열 → axes[0], axes[1]
```

| 코드 | 의미 |
|---|---|
| `plt.subplots(1, 2)` | 1행 2열로 그래프 칸 2개 |
| `axes[0]` | 왼쪽 칸 |
| `figsize=(가로, 세로)` | 그림 크기 (인치) |

## 6. 히스토그램: 수치형 데이터의 분포

```python
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

ages = df['Age'].dropna()          # 결측치는 빼고 그려야 한다
axes[0].hist(ages, bins=20, edgecolor='white')
axes[0].axvline(ages.mean(), color='red', linestyle='--', label='평균')
axes[0].axvline(ages.median(), color='green', linestyle='--', label='중앙값')
axes[0].legend()
axes[0].set_title('나이 분포')

axes[1].hist(df['Fare'], bins=30, edgecolor='white')
axes[1].set_title('운임 분포')

plt.tight_layout()
plt.show()
```

| 옵션 | 의미 |
|---|---|
| `bins` | 막대(구간) 개수 |
| `edgecolor` | 막대 테두리 색 → 막대 구분이 잘 보임 |
| `axvline(x)` | x 위치에 세로선 |
| `label` + `legend()` | 범례 표시 |

### 그래프에서 읽은 것
- **나이**: 종 모양에 가깝고, 평균선과 중앙값선이 가깝다.
- **운임**: 왼쪽에 몰려 있고 오른쪽으로 긴 꼬리 → 소수의 매우 비싼 운임(이상치)이 있다.
  → `describe()`에서 본 "평균 > 중앙값"을 그래프로 확인한 것

## 헷갈렸던 점 / 기억할 것
- 75%는 **3사분위수(Q3)**. 2사분위수(Q2)는 중앙값(50%)이다.
- `fig, ax`에서 `ax`는 그래프 한 칸이다. 칸이 여러 개면 `axes[0]`, `axes[1]`로 접근한다.
- 히스토그램에 결측치가 있으면 경고나 에러가 날 수 있으니 `.dropna()`를 붙인다.
- 0/1 열의 평균은 비율이다 → `groupby(...)['Survived'].mean()` = 생존율
- `value_counts()`와 `nunique()`는 기본적으로 NaN을 빼고 센다.
- 평균과 중앙값 차이가 크면 히스토그램으로 꼭 분포 모양을 확인하기.
